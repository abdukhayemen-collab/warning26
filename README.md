# ضغطة واحدة قد تكلّفك الكثير

عرض توعوي تفاعلي بالعربية (RTL) عن مخاطر الروابط المشبوهة والاختراقات، مع مقدمة محاكاة بصرية وصوتية، وشرائح تعليمية، واختبار قصير.

**إعداد: مروة خليل**

## التشغيل

لا يحتاج المشروع إلى تثبيت أو أدوات بناء:

1. افتح `index.html` مباشرة في المتصفح، أو
2. شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8765
```

ثم افتح: `http://localhost:8765/`

> يبدأ الفحص المحاكى مباشرة عند فتح الصفحة. يمكن تخطي المقدمة من زر **تخطي المقدمة**، أو كتم الصوت وتقليل الحركة من أزرار التحكم.

## الملفات

- `index.html` — بنية العرض والمقدمة والشرائح والاختبار.
- `assets/css/styles.css` — تنسيقات العرض والمقدمة المتجاوبة.
- `assets/js/app.js` — منطق المقدمة، المؤثرات الصوتية، التنقل، والاختبار.
- `assets/fonts/` — خطوط IBM Plex Sans Arabic المضمنة للعمل دون اتصال.
- `assets/img/favicon.svg` — أيقونة الموقع.

## ملاحظات

- المقدمة **محاكاة توعوية فقط**؛ لا تفحص الجهاز، ولا تجمع بيانات، ولا تحتوي روابط حقيقية.
- المؤثرات الصوتية مُولّدة محليًا عبر Web Audio، ولا تحتوي موسيقى. قد يمنع المتصفح التشغيل التلقائي؛ في هذه الحالة تبدأ المؤثرات عند أول تفاعل من المستخدم.
- يدعم العرض التنقل بلوحة المفاتيح والأسهم، وملء الشاشة، وتقليل الحركة.

## الخطوط

يستخدم المشروع خط **IBM Plex Sans Arabic**، المرخّص تحت **SIL Open Font License 1.1**.
